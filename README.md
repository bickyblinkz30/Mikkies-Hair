# 💇 Mikkies Hair — Premium Salon Web App

> *Radiate confidence. Stay cute.*

A full-stack web application built for a professional hair stylist to showcase their work and allow clients to book appointments online.

🔗 **Live Site:** [mikkies-hiar.vercel.app](https://mikkies-hiar.vercel.app)

---

## Features

- 🏠 **Homepage** — Hero section with brand identity and service highlights
- ✂️ **Services Page** — Full service menu including cuts, braiding, wig installation, coloring, treatments, and frontal styling
- 🖼️ **Gallery** — Visual showcase of the stylist's work
- 👤 **About Page** — Stylist profile and brand story
- 📅 **Booking System** — Client appointment request flow powered by Supabase
- 📱 **Fully Responsive** — Optimised for mobile, tablet, and desktop

---
